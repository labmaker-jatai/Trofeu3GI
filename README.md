# 🏆 Troféus da III Gincana Integradora do IFG — Câmpus Jataí

Projeto dos troféus desenvolvidos para a **III Gincana Integradora do Instituto Federal de Goiás (IFG) — Câmpus Jataí**.

Os troféus foram projetados para fabricação em **MDF utilizando corte a laser**, com foco em uma estrutura de montagem simples e adequada ao processo de fabricação digital.

## 📁 Arquivos

O repositório contém os modelos dos troféus nos seguintes formatos:

- **`.DXF`** — arquivo vetorial para projetos e máquinas de corte.
- **`.SVG`** — versão vetorial editável, adequada para diferentes softwares de desenho e preparação para corte.
- **`.WCVR`** — arquivo de projeto utilizado pelo software **AutoLaser**.

### 🛠️ Fabricação

Os arquivos `.WCVR` foram preparados para utilização no **AutoLaser**, software empregado na operação das máquinas de corte a laser equipadas com controladoras **TopWisdom**.

O projeto pode ser utilizado como referência ou ponto de partida para a fabricação dos troféus, permitindo também a edição dos arquivos vetoriais para adaptações de tamanho, material ou personalização.
